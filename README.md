# 💭 Things I believe

**Build before overthinking.**

A working prototype teaches you more than a beautiful architecture diagram.

**Curiosity is a feature.**

Some of the best projects start with a completely unreasonable question.

**Good UX hides complexity.**

People shouldn't need to understand the system to use it.

**Small experiments compound.**

Not everything needs to be production-ready. Some things just need to teach you something.
