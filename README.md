## 👋 A little about me

I enjoy building things and figuring out how things work.

Sometimes that means writing software. Sometimes it's AI, ML or data. Sometimes it's a strange side project that starts with *"I wonder if this would work..."*

I like moving between **engineering, product, design and experimentation** — taking an idea from a rough thought to something tangible. My GitHub is basically a record of that journey, from web to blockchain to data to ML to LLMs to the developer tools I'm building now.

> **Build things. Break things. Learn things. Repeat.**
